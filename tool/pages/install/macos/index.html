Zen for Mac

macOS 12 or newer, Apple Silicon and Intel.

Recommended

ZIP, then Applications

macOS asks you once to allow Zen, because Zen is not signed by Apple.

Download for Mac Apple Silicon and Intel

  1. Download and move

    Download Zen-macOS.zip, open it and drag Zen into Applications.

  2. Open Zen

    macOS says it cannot check Zen for malware. Click Done.

  3. Allow it

    Open System Settings → Privacy & Security, scroll down to *“Zen” was blocked* and click Open Anyway.

  4. Confirm

    Enter your password and click Open Anyway once more. Only the first time.

If something goes wrong

Right-click → Open does not work

Since macOS 15 only Open Anyway in System Settings helps.

macOS asks for keychain access after an update

Choose Always Allow.

Other ways

Prefer the Terminal? This does the same as steps 2 to 4:

xattr -dr com.apple.quarantine /Applications/Zen.app

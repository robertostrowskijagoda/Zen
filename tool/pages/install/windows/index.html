Zen for Windows

Windows 10 or 11. Nothing else to install: everything is in the zip.

Recommended

Portable ZIP

Unpack, run, done. Zen updates itself from GitHub.

Download for Windows x64. On Windows on ARM see Other ways.

  1. Download the zip

    Click the button above and save Zen-Windows.zip.

  2. Unpack the whole zip

    Right-click it and choose Extract All. You get a folder Zen. Keep it whole, with nothing else inside.

  3. Run zen.exe

    Open zen.exe in that folder. If SmartScreen says *Windows protected your PC*, click More info → Run anyway.

If something goes wrong

Where is “Run anyway”?

Click the small More info link in the blue window first; then Run anyway appears.

Smart App Control blocked Zen

Windows 11 with Smart App Control on blocks apps without a code signature, as Zen has none yet, and offers no *Run anyway*. You can turn it off in Windows Security → App & browser control → Smart App Control settings → Off. That lowers protection for the whole computer, so decide for yourself. Or use Zen on your phone or another computer.

My antivirus warns about Zen

New unsigned programs sometimes get false alarms. Compare the zip with the checksums: if they match, it is the file from GitHub. Report the false alarm to the antivirus maker.

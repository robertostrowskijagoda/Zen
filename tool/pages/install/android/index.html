Install the APK file

One file from GitHub. Zen updates itself afterwards.

Download for Android arm64-v8a: fits almost every phone

  1. Download the file

    Tap the button above on your phone. If the browser asks whether to keep the file, choose Download anyway.

  2. Open it and allow once

    Open the downloaded file. If the phone asks, allow your browser to install apps (Allow from this source), then go back.

  3. Install

    Tap Install. If Play Protect warns about an unknown app, choose More details → Install anyway. Then open Zen.

If something goes wrong

“App not installed” or “not compatible”

Your phone may be a 32-bit one or a Chromebook. Try another file:

armeabi-v7a x86_64
The phone says the developer is not verified

Google asks this from 2027. Do it once: Settings → About phone, tap Build number 7 times; then Developer options → Apps from unverified developers, confirm, restart, wait 24 hours and choose permanently. Names differ a little by phone.

Play Protect blocks the install

This is normal outside a store. Choose More details → Install anyway.

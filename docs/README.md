# Zen documentation

**On the website** ([robertostrowskijagoda.github.io/Zen](https://robertostrowskijagoda.github.io/Zen/), 21 languages)

- [Install](https://robertostrowskijagoda.github.io/Zen/install/): one
  recommended way and its own page for Android, iPhone, Windows, Mac and Linux,
  with steps, pictures and downloads.
- [How to use Zen](https://robertostrowskijagoda.github.io/Zen/guide/): the
  basics in ten short parts, linking to the user guide below.
- [Features](https://robertostrowskijagoda.github.io/Zen/features/): what Zen
  is, how it protects you and what it runs on.
- [Support](https://robertostrowskijagoda.github.io/Zen/support/): how to
  report a bug (and what to attach), contact, donations.
- [About](https://robertostrowskijagoda.github.io/Zen/about/): what it is,
  how to check a download, why it is not in the stores.

**For everyone**

- [User guide](guide/README.md): what each part of Zen does and how it works,
  with pictures.
- [Privacy policy](PRIVACY.md) and [terms of use](TERMS.md). Using Zen to
  break the law is forbidden by the terms of use.
- [Zen on Discord](https://discord.gg/g4vHvpKV37): questions, help and
  talk with other people who use Zen.

**Security**

- [Security model](SECURITY_MODEL.md): threats, encryption, what is
  post-quantum and what is still classical, device hardening, limits.
- [Reporting a vulnerability](../SECURITY.md).

**For developers and packagers**

- [Dependencies](DEPENDENCIES.md): libraries, platform APIs and licences.
- [Protocol specification](PROTOCOL.md): frames, records and cryptography on
  the wire.
- [Releases](RELEASES.md): signing, publishing, distribution, updates, the
  website (`tool/pages`, deployed by `.github/workflows/pages.yml`).
- [iPhone in the background](IOS_BACKGROUND.md): what iOS allows without a
  server, what Zen does, and how to test it.
- [Testing](TESTING.md): the network simulator, several apps on one
  computer, the visual tours, translations, CI.
- [Changelog](../CHANGELOG.md).
